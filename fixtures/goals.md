# Objetivos (ficticios, para demo y evals)

> Datos de ejemplo. Los objetivos reales van en `_local-only/goals.md`, que nunca se sube a git.
> Formato: `- [goal:N] Etiqueta corta: descripción`. La etiqueta agrupa la sección "Avanzó".

- [goal:1] Reportes: estabilizar el módulo de reportes, sin timeouts y con tiempos de respuesta aceptables para el cliente.
- [goal:2] Staging: mantener el ambiente disponible para que QA pueda hacer regresión.
- [goal:3] Migración: cerrar la migración de base de datos con revisión y rollback documentado.
- [goal:4] Alertas: diseñar la arquitectura del módulo de alertas.
